หากต้องการอัปเดตโค้ดใหม่ (เช่น มีการแก้ไขหน้าเว็บ เกม หรือระบบ Serial Key) แล้วต้องการลบไฟล์เก่าเพื่ออัปโหลดไฟล์ชุดใหม่เข้าไปแทนที่ ห้ามลบโฟลเดอร์ระบบเด็ดขาด ครับ โดยไฟล์และโฟลเดอร์ที่ ต้องเก็บรักษาไว้ มีดังนี้ครับ:โฟลเดอร์ระบบ GitHub Actions: โฟลเดอร์ .github (ด้านในมีโฟลเดอร์ workflows และไฟล์ build.yml) -> ห้ามลบเด็ดขาด เพราะถ้าลบ ระบบสั่งทำไฟล์ .exe อัตโนมัติจะพังทันที   ไฟล์ระบบตั้งค่าและรันแอป:package.json (ไฟล์ตั้งค่า Electron และ Builder)   main.js (ไฟล์รันระบบหลักและตัวเช็ค Serial Key)   activate.html (หน้าต่างสำหรับกรอก Serial Key)   ส่วนที่สามารถลบแล้วอัปโหลดใหม่ทับได้:โฟลเดอร์เนื้อหาเกมทั้งหมด เช่น assets/, css/, js/, data/ไฟล์หน้าเว็บหลัก เช่น index.html และไฟล์วิดีโอแบ็คกราวด์ต่างๆ   คำแนะนำเพิ่มเติมเพื่อความสะดวก:จริง ๆ แล้วเวลาคุณแก้ไขโค้ด (เช่น แก้ไฟล์ HTML, CSS, หรือ JS) คุณ ไม่จำเป็นต้องลบแล้วอัปโหลดใหม่ทั้งหมด ครับ คุณสามารถกดเข้าไปแก้ไฟล์นั้น ๆ บนหน้าเว็บ GitHub โดยตรง หรือลากไฟล์ใหม่ที่มีชื่อเดิมมาวางทับเพื่ออัปเดต (Commit changes) ได้เลย ระบบจะทำการ Build ไฟล์ .exe เวอร์ชั่นใหม่ให้อัตโนมัติทันทีครับ!
